    DGTS · Digit Span
    Direction
    Mode
    How to play

    Digits flash one at a time, one per second, starting with 3 digits.

    • Forward: type them in the order shown. Backward: type them reversed.
    • Get it right and the next sequence is one digit longer.
    • Easy gives you a second try at each length. On Hard one miss ends the run.
    • Score = the longest sequence you got right. Use the keypad or your keyboard (Enter to submit).
    SWCH · Task Switch
    Green circle → MATH. Is the answer odd or even?
    Red square → ARROWS. Which way do most of them point?
    Mode
    Clock
    Instant feedback
    How to play

    A signal flashes in the middle, then the problem appears. Answer with ← → on your keyboard or the two buttons.

    • Math: ← ODD · EVEN →. Every number is under 100.
    • Arrows: press the direction most arrows point.
    • Hard: both problems appear, top and bottom shuffle. Only the one the signal picked counts — remember it.
    • Super hard: the odd/even keys sometimes swap sides. The buttons always show the current layout.
    • +1 right, −1 wrong. Taking longer than 4 seconds counts as wrong.

    CNFM · Trade Confirm
    Code length
    Speed
    How to play

    The order ticket ID is at the top. Four trade confirmations are below — only one matches exactly.

    • Tap the exact match (or press 1–4 on a keyboard).
    • Decoys differ by one character: look-alikes like 0/O, 1/I, 5/S, 8/B, or two neighbours swapped.
    • You start with 5 seconds per ticket. Every match takes 0.1s, 0.2s or 0.3s off the clock, down to 0.6s.
    • You have 3 lives. A wrong tap or running out of time costs one.
    • Score = number of matches.

    AUDT · Tape Audit

    20 number sequences, 5 minutes. Each has one bad print — find it and type it in. You're not expected to finish them all.

    Extra number

    One extra number has been inserted into this sequence. Type the number that does not fit.

    43, 47, 53, 57, 59, 61, 67, 71
    Consecutive primes — 57 (3 × 19) was inserted.
    Wrong number

    One number in this sequence is wrong. Type the wrong number.

    7, 18, 29, 40, 54, 62, 73, 84
    Add 11 each step — 54 should be 51.
    How to play
    • Questions get harder as you go: 7 easy, 7 medium, 6 hard, drawn from a bank of checked sequences.
    • Type the number and press Submit (or Enter). Skip sends a question to the back of the line — you'll see it again if time is left.
    • No right/wrong feedback until the end. Score = correct answers; wrong answers cost nothing.
    • Patterns to check, in order: differences, ratios, odd/even positions as two separate sequences, differences of differences, squares/cubes/primes, sums of previous terms, alternating operations.
